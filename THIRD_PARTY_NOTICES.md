## Synthesized casting performances

The original casting callouts were synthesized with [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M), whose model is offered under Apache License 2.0, using the MIT-licensed [kokoro-onnx](https://github.com/thewh1teagle/kokoro-onnx) inference project. The generated lines do not imitate a named actor. These references identify the tools used to create the performances; the model and inference packages are not distributed as part of the game download.
